# Front-End-Developer-Project
🔐 Authentication Flow (OTP)

User enters mobile number

OTP is generated via backend API

OTP is validated

Token is received and stored in localStorage

Token is automatically attached to all API requests

Protected routes block unauthenticated access

📤 Document Upload Features

File upload using multipart/form-data

Metadata:

Title

Description

Tags (chips input)

Token-protected upload endpoint

Success & error handling

🔍 Search & Filter Features

Search by:

Keyword (title / description)

Tags

Results displayed in table format

Secure API call with token

👁️ Preview & ⬇️ Download

Preview documents in modal (PDF / images)

Download documents directly

Works with backend file URLs

🏷️ Tags as Chips + Autocomplete

Add tags by typing and pressing Enter

Tags shown as removable chips

Autocomplete suggestions supported

Reusable TagInput component

▶️ How to Run the Project
Prerequisites

Node.js v20+

npm
